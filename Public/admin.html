Falta un paso de configuración

El panel ya está listo, pero todavía no tiene la llave de conexión con la base de datos.

  1. Entra a supabase.com → tu proyecto → Project Settings → API.
  2. Copia la llave anon public.
  3. Pégala en el archivo js/supabase-config.js, en anonKey.
  4. En SQL Editor, ejecuta el archivo supabase-setup.sql.
  5. En Authentication → Users, crea el usuario administrador con su correo y contraseña.
